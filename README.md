# 💡 Smart Classroom | Smart Lamp Dashboard (Flutter App)

แอปพลิเคชันมือถือและเดสก์ท็อปสำหรับควบคุมและมอนิเตอร์ **Smart Lamp & IoT Dashboard** สร้างด้วย **Flutter** โดยถอดแบบหน้าตา สีสัน สไตล์ และฟังก์ชันมาจากหน้าเว็บเดิมใน `smart-lamp-dashboard` แบบ **1:1** (โทนสี Warm Dark `#141210`, สีทองส้ม Amber `#F59E0B` และไฟเรืองแสงสมจริง)

รองรับการใช้งานบน **Android, Windows Desktop, Web (Chrome/Edge) และ iOS** พร้อมเชื่อมต่อ REST API แบบ Real-time

---

## 🎨 หน้าตาและดีไซน์ที่เหมือนหน้าเว็บ 1:1

1. **Navigation Header**
   - โลโก้กล่องไฟสีทองส้ม Gradient พร้อมดวงไฟเรืองแสงและไฟสถานะสีเขียวกระพริบ
   - ชื่อระบบ **"Smart Classroom"** พร้อมป้าย **"IoT v1.0"**
   - แสดงสถานะ **ESP32 Node (192.168.1.105)** และเวลาที่อัปเดตข้อมูลล่าสุดแบบ Real-time
   - ป้ายสถานะ **MongoDB Atlas**
   - ปุ่มรีเฟรช และปุ่มตั้งค่าการเชื่อมต่อ Server

2. **Top 4 Status Cards (Hero Status Bar)**
   - ⚡ **โหมดการทำงาน (Mode)**: แสดง `FORCE ON`, `AUTO` หรือ `FORCE OFF`
   - 💡 **สถานะหลอดไฟ (Lamp)**: แสดง `ON (เปิด)` สว่างเต็มประสิทธิภาพ หรือ `OFF (ปิด)` พร้อม Glow Indicator
   - 🌙 **สภาพแสงแวดล้อม (Light)**: แสดง `DARK (มืด)` / `BRIGHT (สว่าง)` พร้อมระดับเปอร์เซ็นต์และค่าดิบ ADC
   - 🚶‍♂️ **การตรวจจับคน (People)**: แสดง `YES (มีคน)` ตรวจพบคน (DETECTED) หรือ `NO` พื้นที่ว่าง

3. **แผงควบคุมไฟอัจฉริยะ (Smart Lamp Controller)**
   - **Realistic Warm Lamp Visualizer**: ภาพจำลองหลอดไฟแขวนพร้อมสายไฟ, ขั้วหลอด, ไส้หลอด และแสงสะท้อนบนพื้น (สามารถแตะที่ตัวหลอดไฟเพื่อเปิด/ปิดได้ทันที)
   - **สวิตช์ไฟหลัก**: สวิตช์เปิด/ปิด Relay ของหลอดไฟ
   - **ความสว่าง (PWM Dimmer)**: แถบเลื่อนปรับความสว่าง 10% - 100%
   - **3 ปุ่มเลือกโหมด**:
     - `FORCE ON` (เปิดตลอด)
     - `AUTO` (ตามแสง/คน)
     - `FORCE OFF` (ปิดตลอด)
   - **กล่องเงื่อนไข AUTO**: แสดงกติกาการเปิดไฟอัตโนมัติเมื่อแสง < 30% และมีคนอยู่

4. **เซ็นเซอร์ & การตรวจวัดสภาพแวดล้อม (Sensor Metrics)**
   - 🌡️ **สภาพอากาศ & อุณหภูมิ (Climate DHT22)**:
     - การ์ดอุณหภูมิ (Temp) ตัวเลขใหญ่ 3xl สีทองส้ม พร้อมแถบวัดระดับสีรุ้ง (ฟ้า-ส้ม-แดง)
     - การ์ดความชื้น (Humidity) ตัวเลขใหญ่ 3xl พร้อมแถบวัดระดับสีทอง
   - ☀️ **ระดับแสงแวดล้อม (Light Sensor - LDR)**:
     - แสดงค่าเปอร์เซ็นต์ (0-100) และค่าดิบ ADC (0-4095)
     - แถบความสว่าง 3 สเต็ป: `0% (มืดสนิท)`, `50% (แสงพอดี)`, `100% (สว่างจ้า)`
     - เกณฑ์เปิดไฟอัตโนมัติ: `< 30%`
   - 📡 **การตรวจจับคน (Proximity Sensor)**:
     - ป้ายสถานะ `DETECTED` (สีเขียวสว่าง) หรือ `CLEAR`
     - สัญลักษณ์เรดาร์พร้อมไอคอนคน

5. **Serial Monitor Console (Arduino IDE Style)**
   - หน้าจอ Terminal คอนโซลสีเข้ม `#0E1318` เหมือน Arduino IDE
   - แสดงสถานะพอร์ต `COM4 (115200 baud)`
   - สตรีมข้อความ Telemetry Payload แบบ Real-time พร้อมเวลา `[HH:mm:ss]`
   - ปุ่ม Auto-scroll, Clear และ Copy ทั้งหมดลงคลิปบอร์ด

6. **กราฟแนวโน้มข้อมูลสภาพแวดล้อม (Telemetry Real-time Charts)**
   - พัฒนาด้วย `fl_chart` สีและเส้นโค้งนุ่มนวลแบบ Chart.js บนเว็บ
   - แท็บสลับดู: **ภาพรวมทั้งหมด**, **อุณหภูมิ & ความชื้น**, **ระดับแสง (Light)**
   - เลือกช่วงข้อมูล **1 ชั่วโมง**, **24 ชั่วโมง**, **7 วัน** หรือ **ทั้งหมด** พร้อมค่าสถิติ min/avg/max
   - แตะดูค่าตัวเลขบนกราฟได้แบบอินเทอร์แอคทีฟ

7. **เครื่องมือจำลองเซ็นเซอร์สด (Live Sensor Control Bench)**
   - สไลเดอร์ปรับค่าอุณหภูมิ (15°C - 42°C)
   - สไลเดอร์ปรับค่าความชื้น (20% - 95%)
   - สไลเดอร์ปรับระดับแสง (0% - 100%)
   - สวิตช์จำลองการตรวจจับคน (DETECTED / CLEAR)
   - ปุ่ม **"ส่งข้อมูลจำลองไปยังเซิร์ฟเวอร์"** และปุ่ม **"คืนค่าเป๊ะ"** สำหรับทดสอบระบบ

8. **ตั้งค่า Backend URL**
   - รองรับ Render Cloud (`https://smart-lamp-dashboardv2.onrender.com`) หรือ Localhost / Local IP
   - มีปุ่มทดสอบการเชื่อมต่อเซิร์ฟเวอร์ก่อนบันทึก

9. **การแจ้งเตือน คำแนะนำ และทางลัด**
   - ตั้งเกณฑ์แจ้งเตือนอุณหภูมิ, ห้องว่างแต่ไฟยังเปิด และอุปกรณ์ออฟไลน์เกิน 5 นาที
   - แสดงคำแนะนำจากสถานะห้องและแนวโน้มค่าที่วัดได้
   - ใช้ฉาก **สอน**, **พัก** และ **ปิดห้อง** เพื่อส่งคำสั่งโหมดและความสว่างไปยัง backend
   - เก็บประวัติการควบคุมและการเปลี่ยนสถานะที่ตรวจพบไว้ในเครื่อง (สูงสุด 100 รายการ)
   - สถานะออฟไลน์แสดงระยะเวลาตั้งแต่รับข้อมูลสำเร็จครั้งล่าสุด

การตั้งค่าเกณฑ์แจ้งเตือนและประวัติเหตุการณ์จัดเก็บในเครื่อง การแจ้งเตือนจะแสดงภายใน Dashboard ขณะเปิดแอปเท่านั้น ยังไม่มี push notification หรือการตั้งเวลาเปิด-ปิดไฟ เนื่องจาก backend ปัจจุบันยังไม่มี API สำหรับการทำงานเหล่านั้น ช่วงเวลาของกราฟขึ้นอยู่กับข้อมูลย้อนหลังที่ backend ส่งกลับมา (แอปร้องขอสูงสุด 500 จุด)

## 🚀 วิธีการรันและทดสอบแอปพลิเคชัน

เปิด PowerShell หรือ Terminal ไปที่โฟลเดอร์โปรเจกต์:
```powershell
cd C:\Users\kaiwi\Desktop\smart-lamp-dashboard-app
```

### 1. ทดสอบเปิดดูหน้าจอแอปบนเบราว์เซอร์ทันที
```powershell
flutter run -d chrome
```

### 2. รันเป็นโปรแกรม Windows บนหน้าจอคอมพิวเตอร์
```powershell
flutter run -d windows
```

### 3. รันบนโทรศัพท์มือถือ Android หรือ Android Emulator
```powershell
flutter run
```

### 4. คอมไพล์เป็นไฟล์ติดตั้ง APK (.apk)
```powershell
flutter build apk --release
```
ไฟล์ APK จะถูกสร้างไว้ที่:
`build/app/outputs/flutter-apk/app-release.apk`
